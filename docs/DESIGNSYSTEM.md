Life & Legacy Journal — Design System
Personality: Quietly powerful. Calm, trustworthy, intimate, reflective, premium.
Not a medical app. Not a productivity tool. Not a dating app. Not social media.

It should feel like: Personal journal + Growth companion + Relationship space + Life planner.

Typography
·	Primary font: Geist Sans (or system-ui)
·	Headings: tracking-tight, bold
·	Body: comfortable line-height, secondary color for supporting text
·	Avoid pure black; use Charcoal (#1F2937)

Components Principles
·	Soft rounded cards (1rem radius)
·	Subtle shadows only
·	Progress bars use area-specific accent colors
·	Buttons: primary indigo for main actions, outline for secondary
·	Never use bright red for marriage — keep Dusty Rose mature and calm
·	Gold is reserved for meaningful achievements, not everyday UI
